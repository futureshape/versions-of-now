# CRT BBC Clock

Prototype:

```text
simulator/crt-bbc-clock.html
```

ESPHome config:

```text
esphome/crt-bbc-clock.yaml
```

This clock targets an original ESP32 with composite video output generated by
the DAC on GPIO25. It uses a local ESPHome component wrapping the vendored
`aquaticus/esp32_composite_video_lib` ESP-IDF component.

Hardware assumptions:

- Board: ESP32 DevKit-style board with the original ESP32 DAC peripheral.
- Composite output: GPIO25 through the resistor network documented by
  `aquaticus/esp32_composite_video_lib`.
- Clock video mode: PAL 384x288, 1 bit per pixel, black and white.
- ESP-IDF compiler optimization: performance (`-O2`), required by the composite
  video library.
- Time source: shared SNTP config from `esphome/shared/network.yaml`.

On boot, the device shows the library's PAL 384x288 Philips PM5544 test pattern
until SNTP time is valid, then switches to the PAL 384x288 clock renderer.

Clock frames are rendered after the composite library signals the end of the
visible PAL frame, keeping framebuffer updates aligned with vertical blanking.

The vendored composite library is GPL-3.0-or-later; its license is included in
`esphome/components/esp32_composite_video_lib/LICENSE`.
